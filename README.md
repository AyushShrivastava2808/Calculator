# 🧮 Calculator

A simple, responsive, and interactive calculator built using **HTML, CSS, and JavaScript**. This project demonstrates core web development skills including DOM manipulation, event handling, and responsive design.

---

## 🚀 Features 
- Responsive design for desktop and mobile screens  
- Clean and user-friendly interface  
- Error handling for invalid inputs  

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the calculator  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6)** – Logic and interactivity
